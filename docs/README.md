Cada fase del proyecto tiene un documento con tres secciones obligatorias:

1. **Qué se hizo** — decisiones y entregables.
2. **Cómo se verifica** — comandos y checklist reproducibles.
3. **Qué queda pendiente** — deuda técnica y siguientes pasos.

## Convenciones

- Los documentos se actualizan **al terminar** cada fase, no al empezar.
- Los comandos están escritos para **PowerShell en Windows**.
- Las rutas de archivos son relativas a la raíz del repositorio.
- Todo lo que el usuario final ve está en **español**.
